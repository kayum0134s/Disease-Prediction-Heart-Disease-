About CardioPredict

A startup-grade AI healthcare platform built for cardiovascular disease prediction.

🚀 Project Overview

CardioPredict is a production-grade, AI-powered cardiovascular risk assessment platform. It trains an ensemble of three Machine Learning models on the UCI Heart Disease dataset and exposes a REST API for real-time prediction, model comparison, and automated medical report generation.

The system processes 13 clinical parameters — including age, blood pressure, cholesterol, ECG results, and thalassemia type — through a rigorous ML pipeline to output probabilistic risk scores (0–100%) and classify patients into four risk bands: Low, Moderate, High, and Critical.

🔬 ML Workflow Pipeline
Step 1 — Dataset Collection
UCI Heart Disease dataset (14 features, 303 original records). Synthetic expansion to 1000 samples for robust training.
Step 2 — Data Cleaning & Preprocessing
Median imputation for missing values, duplicate removal, target binarization. One-hot encoding for categorical features (cp, restecg, slope, thal, exang).
Step 3 — Feature Engineering & Scaling
StandardScaler applied to continuous features (age, trestbps, chol, thalach, oldpeak). Scaler fit on training set only to prevent data leakage.
Step 4 — Train-Test Split
80% training / 20% test split with stratification to preserve class balance across both sets.
Step 5 — Model Training
Logistic Regression (C=1.0, max_iter=1000), Random Forest (100 estimators), SVM (RBF kernel, probability=True). All trained and persisted as .pkl files.
Step 6 — Accuracy Comparison
Accuracy, Precision, Recall, F1-Score, and ROC-AUC computed for each model. Confusion matrices and ROC curves generated as base64 PNG images.
Step 7 — Prediction & Reporting
Random Forest serves as the final prediction engine. Risk score = RF predict_proba × 100. Results saved to SQLite and PDF reports generated on demand.

🎓 Viva Q&A GuideClick to expand
Why did you choose Random Forest as the final model? +
Random Forest consistently achieves the highest accuracy (87%+) and ROC-AUC on this dataset because it handles non-linear feature interactions, is robust to outliers, and provides feature importance scores. It also reduces overfitting through bagging (bootstrap aggregation) compared to a single decision tree.
What is the difference between precision and recall in this context? +
Precision = of all patients predicted as having heart disease, how many actually do (avoids false alarms). Recall = of all patients who actually have heart disease, how many did we correctly identify (avoids missing cases). In a medical context, high recall is critical — missing a true positive (heart disease patient) is more dangerous than a false positive.
What is a confusion matrix and how do you read it? +
A 2×2 matrix showing True Positives (disease, predicted disease), True Negatives (no disease, predicted no disease), False Positives (no disease, predicted disease — Type I error), and False Negatives (disease, predicted no disease — Type II error). In cardiovascular disease prediction, minimizing False Negatives is the clinical priority.
How did you handle data preprocessing? +
Median imputation for missing values (robust to outliers), duplicate removal, one-hot encoding for categorical features (cp, restecg, slope, thal, exang), and StandardScaler for continuous features. Critically, the scaler was fit only on the training set to prevent data leakage into the test set.
What is ROC-AUC and why is it important? +
ROC (Receiver Operating Characteristic) curve plots True Positive Rate vs. False Positive Rate at all classification thresholds. AUC (Area Under Curve) summarizes the curve as a single number — 1.0 is perfect, 0.5 is random. AUC is important because it's threshold-independent and works well with imbalanced datasets common in medical classification.
How does SVM work for classification? +
Support Vector Machine finds the optimal hyperplane that maximizes the margin between classes. With RBF (Radial Basis Function) kernel, it can classify non-linearly separable data by mapping it to a higher-dimensional space. The kernel trick computes dot products in this space without explicitly mapping — making it computationally efficient.
What are the most important features for heart disease prediction? +
According to the Random Forest feature importance analysis: thal (thalassemia type), ca (number of major vessels), cp (chest pain type), oldpeak (ST depression), and thalach (max heart rate) are typically the top predictors. This aligns with clinical literature on cardiovascular risk factors.
